About This Project

I created this game as a solo developer for the 2024 IGM X granola.gg Game Jam (October 4-6, 2024) under 24 hours. Inspired by classic platformers like Mario and Sonic, I set out to create a retro-themed 2D platformer. Due to time constraints, I focused on building a streamlined platformer with core features including audio, dynamic events, moving fireballs, and falling platforms. The objective is to reach the end of the trail and claim victory.

This project allowed me to enhance my skills in game design, level creation, and rapid prototyping using Unity especially in a non-team setting. It was a rewarding experience to see my ideas being brought to life in such a short time frame and done entirely by myself. Some of the problems were of course time management and scope, but I learned to prioritize essential features before adding extra polish. Overall, Pixel Reform was a fun and educational project that strengthened my game design abilities using Unity and C#.

My Process & Contributions

My workflow for this project involved several key steps:

Conceptualization: I brainstormed ideas for a retro-style platformer that could be executed within the 24-hour time limit using my current knowledge and game design skills using Unity and C# in 2D design. I focused on simple mechanics.

Design & Prototyping: I created a basic level layout within Unity and began implementing core mechanics, and gameplay elements. I prioritized functionality over aesthetics initially to ensure a playable experience. I looked for free asset to use in Unity allowing me to focus on gameplay over aesthetics.

design: I built out the game using Unity, coding in C# to handle player movement, environment behavior, and level progression. I also integrated audio to add detail to the experience. In addition, since most of the mechanic in 2D were simple I decided to add a twist to the gameplay mechanic like the falling platforms making the game more challenging.

Testing & Iteration: I playtested the game multiple times to ensure the game was playable from start to finish. I made adjustments to level design and mechanics based on the playtests I conducted.

Finalization: I polished the game by fixing bugs, optimizing performance, and adding final touches to the visuals and audio. I then packaged the game for submission to the game jam platform called granola.gg where the judges were able to play and rate my game.
